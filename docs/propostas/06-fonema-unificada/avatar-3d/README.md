## Regras aplicadas
- Sem joias, colares, brincos, pulseiras, anéis, coroas ou maquiagem.
- Óculos, aparelho auditivo e cadeira de rodas são **acessibilidade**: grátis e não contam como adorno.
- A criança **não** envia foto. Monta o avatar escolhendo peças.

## Pontos para o dono decidir
- Nas duas linhas de diversidade, a menina indígena aparece com **pintura facial tradicional**. É expressão cultural, não joia, mas pode ser lida como "adorno". Manter como opção cultural respeitosa (ideal: validar com consultoria indígena) ou retirar?
- Algumas pranchas repetem itens (bola, caderno, telescópio aparecem duas vezes em `utensilios-a`). Na produção, cada item vira um modelo único.

## Como vira produto
Na produção final, cada peça (cabelo, roupa, utensílio) é um **modelo 3D separado** (glTF) num personagem-base com encaixe. Essas pranchas são a direção de arte para a equipe 3D. O criador de avatar mostra o personagem girando em 3D no app.
