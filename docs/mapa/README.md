# Mapa completo do FONEMA

Visão de uma página de toda a plataforma (13/11/2026): para quem é, a jornada da criança (R0–R10 e Maternal), o ciclo da sessão, as ferramentas, a motivação, o acompanhamento, a Academia, a tecnologia, o universo e a linha do tempo. Os números vêm dos documentos do repositório; as imagens são artes e capturas que já existiam (nenhuma imagem nova foi gerada).

![Mapa completo](mapa-completo.png)
