# Decisões do dono do projeto

As decisões são a **fonte de verdade** do FONEMA. Quando um documento (pesquisa, síntese, proposta, arte) conflitar com uma decisão, **vale a decisão mais recente**. As decisões não são reescritas: quando uma decisão nova muda algo de uma antiga, a antiga recebe uma nota *"Atualizado pela D0xx"* no ponto afetado.

Para criar uma decisão nova, veja [`../CONVENCOES.md`](../CONVENCOES.md) §3.
