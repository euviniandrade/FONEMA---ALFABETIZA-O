# D033 — Fichas de leitura por campo semântico, com a boquinha em cima de cada letra

Data: 2026-11-17. Origem: pedido do dono.

## O que foi pedido
Fichas de leitura organizadas por **campo semântico** (ex.: animais). A palavra aparece escrita, **sem figura** (ex.: MACACO).
Em cima de cada letra, uma **boquinha se movimenta** fazendo o som daquela letra; "Vamos ler juntos?": o app, a criança e a guia
leem som a som; "O que ficou?" → a criança diz/escolhe e **a figura aparece** (macaco). Objetivo: decifrar o som de cada letra
(consciência fonêmica) e associar som e letra.
Níveis, do mais apoiado ao mais desafiador:
1. Palavra escrita + boquinha e som em cada letra → ler junto → revelar a figura.
2. Só o som (e, num degrau, as figuras como opções) para a criança decifrar a palavra.
3. Só a imagem da boquinha e as letras: ligar cada letra à boquinha certa.
4. Só a imagem da boca: descobrir a letra/palavra (o mais difícil).

## Como o projeto aplica (decisão do projeto)
- Palavras do campo semântico só entram para LER quando todos os sons já foram ensinados (regra 2; docs/pedagogia/05); as outras
  ficam trancadas ("em breve") ou só para ouvir. A boquinha mostra o som da letra NAQUELA posição (ex.: o O final de "macaco" soa /u/).
- Leitura letra a letra, sem família silábica (regra 6); som puro, nunca o nome da letra (regra 1).
- "Ler junto" (nível 1) é prática guiada: não conta como domínio; a escolha final da figura sem ajuda conta como leitura avaliada.
- Níveis 3–4 (boca ↔ letra) treinam a consciência articulatória (Soares, Alfaletrar, p. 146, usa o ponto de articulação); só com sons
  de boca visualmente diferentes entre si (sons de boca igual, como /t/ × /d/ × /n/ ou /f/ × /v/, nunca na mesma rodada).
